# 📝 Deorn

A cross-platform note-taking application built with **React Native** and **Go**, featuring **real-time synchronization** across devices. Create, edit, and organize notes with instant updates powered by WebSockets.

## 🔄 Real-Time Synchronization

The application maintains a persistent WebSocket connection.

Whenever a user:

- Creates a note
- Updates a note
- Deletes a note

the server broadcasts the change to all connected clients, ensuring every device stays synchronized instantly.
